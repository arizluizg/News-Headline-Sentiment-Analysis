# Philippines News Headlines: Sentiment Analysis

End-to-end NLP pipeline that classifies Philippine news headlines as **Positive** or **Negative**.

## Dataset
- File: `Philippines-News-Headlines-Dataset-for-Sentiment-Analysis.csv`
- Columns: `Date`, `Headlines`
- The dataset has no human-written labels. Labels are generated with a TextBlob polarity rule:
  - Positive if polarity > +0.05
  - Negative if polarity < -0.05
  - Near-neutral headlines are dropped
- A context-override rule labels headlines like "Inflation hits new high" as Negative, since TextBlob scores growth words as positive.
- **Limitation:** model scores measure agreement with these pseudo-labels, not with human annotators.

## Setup
1. Install Python 3.10+ and VS Code with the **Python** and **Jupyter** extensions.
2. Install the packages:
```
   pip install textblob seaborn scikit-learn joblib matplotlib pandas numpy ipywidgets
```
3. Put the dataset CSV in the `Datasets/` folder next to the notebook.

## How to run
1. Open the folder in VS Code and open `news-headline.ipynb`.
2. Select your Python kernel (top right).
3. Click **Restart > Run All**, or run the cells from the top in order.
4. The notebook trains the models, saves the best pipeline to `news_sentiment_artifacts/`, and reloads it for predictions.

## Making predictions
Use the widget at the end of the notebook, or call the helper directly:
```python
predict_headline("BSP keeps policy rates unchanged.")
```
This prints the predicted sentiment, the confidence, and the per-class probabilities.

To use the saved model outside the notebook:
```python
from news_predictor import NewsSentimentPredictor
predictor = NewsSentimentPredictor("news_sentiment_artifacts/ph_news_sentiment_pipeline.joblib")
print(predictor.predict_one("Oil prices rise as global demand strengthens."))
```

## Troubleshooting
| Problem | Fix |
|---|---|
| `ModuleNotFoundError` | Run `%pip install <package>` in a cell, then restart the kernel |
| `FileNotFoundError` for the CSV | Check that `Datasets/` is next to the notebook; the error prints the current folder |
| Widget shows "Could not render content" | Restart the kernel and re-run the cell, or run `%pip install -U ipywidgets` |
| `NameError: predictor` | Run the earlier cells first so the model is trained and loaded |
