# Philippines News Headlines — Semantic Sentiment Analysis

A Deep Learning, context-aware sentiment analysis project for **65,006 Philippine news headlines (2014–2023)** built directly inside a streamlined **6-section (6-Markdown) Jupyter Notebook** ([Semantic/news-headline-semantic.ipynb](file:///c:/Users/ArizLuiz/Documents/Electives/Semantic/news-headline-semantic.ipynb)), paired with an offline **Tkinter** desktop application ([Semantic/app_tk.py](file:///c:/Users/ArizLuiz/Documents/Electives/Semantic/app_tk.py)) that compares the semantic model side-by-side against the companion Rule-Based pipeline.

> **Responsible AI Note:** The source CSV has no original human sentiment labels. Training labels are generated by a pretrained Transformer teacher (`distilbert-base-uncased-finetuned-sst-2-english`). Held-out test metrics measure **agreement with teacher labels**, supplemented by independent semantic stress tests and a 150-headline human-validation worksheet (`Semantic/human_label_sample.csv`).

## Notebook Structure (`Semantic/news-headline-semantic.ipynb` — Exactly 6 Markdown Sections)

1. **1. Feedforward Neural Networks and Perceptrons** — Week 04 theory + code: setup & imports, dataset/teacher/embedding preparation, from-scratch NumPy activations (`ReLU`, `Sigmoid`, `Tanh`, `Softmax`), Binary Cross-Entropy vs. MSE loss, Perceptron (`AND`/`OR`/`XOR`), Forward Pass, `NumpyMLP` Backpropagation, and Numerical Gradient Check.
2. **2. Optimization and Training Dynamics in Deep Learning** — Week 05 theory + code: from-scratch `SGD`, `SGD + Momentum`, and `Adam`, Learning-Rate sweeps, Overfitting, Early Stopping, Dropout (`0.0`, `0.3`, `0.5`), and scikit-learn optimizer loss/validation curves.
3. **3. Convolutional Neural Networks (CNNs)** — Week 06 theory + code: Convolution, Padding/Stride, Pooling, Receptive Fields, Translation Equivariance vs. Invariance, why 1D CNNs miss long-range negation/contrast cues in news headlines, and a runnable `1D-CNN vs. Transformer` empirical comparison on Philippine news headlines.
4. **4. Transfer Learning and Pretrained Models** — Week 07 theory + code: Feature Extraction vs. Partial Fine-Tuning vs. Full Fine-Tuning, pretrained vision (`ResNet`, `VGG`, `EfficientNet`) vs. NLP Transformer backbones (`all-MiniLM-L6-v2`, `BAAI/bge-small-en-v1.5`, `DistilBERT`), cached sentence embeddings, PCA projection, and the **Semantic Negation Geometry Probe**.
5. **5. Project Methodology, Comprehensive EDA, Model Comparison & Model Evaluation** — Full EDA on 100% of all `64,341` unique clean headlines (`2014–2023`), SST-2 weak-label vs. 3-class RoBERTa domain-bias audit, 7-model validation comparison, Week 07 Partial Fine-Tuning (`distilbert-base-uncased` Top 2/6 layers = `33.3%` + CLS/Mean PyTorch BN/ReLU/Dropout MLP + Soft-Target Distillation), and untouched held-out Before-vs-After test evaluation (`11,545` headlines).
6. **6. Project Setup, Implementation, Semantic Testing, Phrase Analysis & User Guide** — Offline packaging (`semantic_artifacts/` + `semantic_predictor.py`), Task 11B/11E stress tests (24-sentence 4-way + 34-sentence 10-category vs. Rule-Based), linguistic phrase-by-phrase occlusion breakdown, `human_label_sample.csv` validation workflow, robustness checks, Responsible AI caveats, environment setup, and `app_tk.py` user guide.
