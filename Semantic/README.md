# Philippines News Headlines — Semantic Sentiment Analysis

A context-aware sentiment-analysis project for Philippine news headlines. This notebook represents each headline as a sentence embedding and trains a classifier on top of those embeddings. It is the semantic companion to `news-headline.ipynb`, which contains the earlier rule-based / bag-of-words approach.

> **Important:** The semantic model is trained using labels generated by a pretrained sentiment model. Unless the human-label validation section has been completed, the reported test metrics measure agreement with that teacher model—not verified accuracy against human judgment.

## Project overview

The semantic pipeline is designed to consider a headline as a whole rather than relying only on individual word counts. It uses:

1. **Teacher labeling:** `distilbert-base-uncased-finetuned-sst-2-english` generates Positive/Negative labels and confidence scores.
2. **Confidence filtering:** headlines below the configured teacher-confidence threshold are excluded from the labeled training set.
3. **Sentence embeddings:** `sentence-transformers/all-MiniLM-L6-v2` converts each headline into a normalized 384-dimensional vector. The embedding model is frozen; it is not fine-tuned in this notebook.
4. **Classifier comparison:** a majority-class baseline, tuned Logistic Regression, and an MLP (`MLPClassifier`) are compared. The selected classifier is chosen using stratified cross-validation on the training split.
5. **Evaluation:** the selected model is evaluated on a held-out test split, followed by a small hand-written stress test and an optional human-labeled evaluation.

The notebook also contains educational, from-scratch NumPy demonstrations of neural-network fundamentals, backpropagation, gradient descent, Adam, learning rates, overfitting, and dropout. These are learning experiments; the final packaged classifier is selected separately in Section 9.

## Dataset

The notebook uses `Philippines-News-Headlines-Dataset-for-Sentiment-Analysis.csv`, with the columns:

- `Date` — publication date, used for dataset coverage and time-based exploration.
- `Headlines` — headline text used for sentiment labeling and model input.

The source dataset does not contain human-written sentiment labels. The notebook removes missing/blank headlines, normalizes repeated whitespace, and removes exact duplicate headline text. It preserves the headline wording and punctuation so that negation and other context cues remain available to the sentence encoder.

### Default data settings

The main configuration is near the beginning of the notebook:

| Setting | Default | Purpose |
|---|---:|---|
| `SEED` | `42` | Reproducibility |
| `SAMPLE_SIZE` | `20_000` | Maximum number of cleaned headlines sampled for a run; set to `None` to use all cleaned headlines |
| `TEACHER_MODEL` | `distilbert-base-uncased-finetuned-sst-2-english` | Generates the training labels |
| `EMBEDDER_MODEL` | `sentence-transformers/all-MiniLM-L6-v2` | Generates 384-dimensional sentence embeddings |
| `MIN_TEACHER_CONF` | `0.80` | Minimum teacher confidence required to keep a headline |
| `TEST_SIZE` | `0.20` | Held-out test proportion |
| `CV_FOLDS` | `5` | Stratified cross-validation folds for model selection |

Headlines below `MIN_TEACHER_CONF` are filtered out. The resulting task is binary Positive/Negative classification; neutral or uncertain headlines are not modeled as a third class in the current notebook.

## Methods and notebook sections

The notebook is organized into the following workflow:

1. **Setup and reproducibility** — imports, random seeds, device detection, and configuration.
2. **Data loading and cleaning** — loads the CSV, cleans headline text, removes blank and duplicate headlines, and optionally samples the data.
3. **Teacher labeling** — obtains teacher labels, confidence scores, and Positive probabilities; caches the results.
4. **Train/test split** — creates a stratified 80/20 split after confidence filtering.
5. **Exploratory data analysis** — examines dataset coverage and training-split headline and label characteristics.
6. **Sentence embeddings** — creates or loads normalized MiniLM embeddings.
7. **Neural-network foundations** — demonstrates perceptrons, activation functions, cross-entropy, forward propagation, and backpropagation with NumPy.
8. **Training dynamics** — demonstrates gradient descent, Adam, learning-rate behavior, overfitting, and dropout using a from-scratch NumPy network.
9. **Model comparison and tuning** — compares a majority-class baseline, Logistic Regression, and an MLP using five-fold stratified cross-validation and macro-F1.
10. **Test evaluation** — evaluates the selected classifier on the held-out test split.
11. **Packaging** — saves the selected classifier, label encoder, local embedding model, metadata, and creates `semantic_predictor.py`.
12. **Negation stress test** — compares semantic predictions with a small hand-written set of Positive/Negative examples; also compares the teacher and, if available, the legacy rule-based model.
13. **Phrase explanation** — estimates phrase impact by removing phrases and observing the change in Positive probability.
14. **Human-label validation** — creates a sample of real test headlines for manual annotation and compares predictions against completed human labels.
15. **Robustness checks** — checks how the predictor handles empty, invalid, or unusually long inputs.
16. **Limitations and responsible use** — discusses domain limitations and appropriate interpretation.
17. **Summary** — prints results and lists generated files.

## Generated model artifacts and prediction

Section 11 writes the deployable semantic model files to `semantic_artifacts/` and creates `semantic_predictor.py` in the project root. The artifact folder contains:

- `semantic_classifier.joblib` — selected scikit-learn classifier.
- `label_encoder.joblib` — maps encoded classes back to Positive/Negative labels.
- `model_metadata.json` — model settings, source-data hash, software versions, and test metrics.
- `embedder/` — local saved copy of the MiniLM sentence-embedding model.

After running the packaging section (or when the saved artifacts are already present), predictions can be made with:

```python
from semantic_predictor import SemanticSentimentPredictor

predictor = SemanticSentimentPredictor("semantic_artifacts")

result = predictor.predict_one("BSP keeps policy rates unchanged.")
print(result["prediction"])
print(result["confidence"])
print(result["probabilities"])

# Optional phrase-by-phrase impact explanation
explanation = predictor.explain_one("The president is not bad.")
for item in explanation:
    print(item)
```

The predictor validates input text and returns the predicted label, confidence, and class probabilities. Phrase explanations are heuristic and should not be interpreted as causal explanations.

## Human-label validation

Section 14 creates `human_label_sample.csv` with up to 150 headlines randomly sampled from the held-out test set and an empty `human_label` column. Review the headlines and manually enter `Positive` or `Negative`. Leave uncertain examples blank rather than guessing, then rerun the validation cell. The notebook requires at least 30 completed labels before it reports the human-label comparison.

These manual annotations provide a more independent check than comparing the student model only with its teacher. Do not describe teacher-agreement metrics as human-validated accuracy.

## Evaluation notes

- Model selection uses stratified cross-validation on the training split only, scored with macro-F1.
- The final test split is held out from model selection.
- Test accuracy, macro-F1, and ROC-AUC measure agreement with the teacher-generated labels, not necessarily agreement with human sentiment judgments.
- The hand-written stress test is a small diagnostic set; it is not a representative estimate of real-world accuracy.
- The from-scratch NumPy optimizer and dropout experiments are educational demonstrations. The final packaged classifier is selected separately in Section 9. The scikit-learn `MLPClassifier` does not use the dropout layer from the NumPy demonstration; it uses its own settings, including L2 regularization through `alpha` and early stopping.

## Limitations and responsible use

1. **Teacher-label limitation:** the teacher was fine-tuned on movie-review sentiment data, not Philippine news. Its labels may not transfer reliably to political, economic, disaster, or public-service headlines.
2. **Not human ground truth:** the source dataset has no original sentiment labels. Human evaluation is needed to estimate agreement with people's judgments.
3. **Binary output:** the current pipeline predicts Positive or Negative. Low-confidence teacher examples are excluded, and the deployed model does not have a Neutral class.
4. **Language coverage:** the notebook's models are English-oriented. Filipino, Taglish, slang, and regional-language headlines have not been established as supported.
5. **Sentiment is not the same as whether an event is good or bad:** interpretation can depend on context, affected groups, and domain knowledge.
6. **Heuristic explanations:** phrase impact is estimated by removing text and observing score changes. It describes model behavior, not causal meaning.
7. **Not for high-stakes decisions:** predictions are experimental and should not be used as the sole basis for financial, policy, or other consequential decisions.
